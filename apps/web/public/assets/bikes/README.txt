Bike imagery for the Bike Booking section.

Each bike id in src/features/bikes/mock/bikes.mock.ts has three 960 x 640 WebP views:
  <bike-id>-1.webp  studio view
  <bike-id>-2.webp  close-up
  <bike-id>-3.webp  city view

The current files are original shaded illustrations generated by
apps/web/scripts/generate-bike-art.mjs (node scripts/generate-bike-art.mjs).
No third-party artwork and no manufacturer logos.

To use licensed photographs: replace the files here, keeping the same names and size.
Nothing else needs to change. (Remember to credit them in assets-src/images/credits.json.)

The hero banner lives in public/assets/banners/bike-{1024,1920}.webp.
