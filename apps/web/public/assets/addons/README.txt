Meal and baggage cards use built-in vector artwork (sharp at any size).

To show a real photograph instead, just save it in this folder as <id>.webp
(1600x1200 recommended). No code change needed - it is picked up automatically.
A card with no file keeps its artwork.

Meal ids:    veg-dum-biryani, chicken-biryani, dal-makhani-combo, paneer-tikka-wrap,
             chicken-club-sandwich, masala-omelette, fresh-fruit-bowl, samosa-chai
Baggage ids: bag-5, bag-10, bag-15, bag-20, bag-25, bag-30
